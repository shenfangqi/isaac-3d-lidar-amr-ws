`TEMP_ESTIMATE_NOT_CALIBRATED`：本次证据缩小了合理范围，但没有把单一木地板结果

## 2. Jetson 确定性启动链

新增入口：

```bash
scripts/jetson_navigation_start.sh \
  /home/shenfq/Projects/isaac_ros-dev/maps/real/carbot_site_route_retry_20260919.yaml \
  INITIAL_X_M INITIAL_Y_M INITIAL_YAW_RAD navigation-safe
```

它固定执行以下顺序：

1. 以 `autostart:=false` 重建导航容器；
2. 运行只读前置检查，确认服务、传感器、唯一 odom owner、TF 和静默速度拓扑；
3. 只激活 `map_server` 与 `amcl`；
4. 在一个长生命周期 DDS 进程内发布初始位姿，等待 `/amcl_pose` 与
   `map -> odom`；
5. 激活 controller、planner、behavior、BT、waypoint 与 velocity smoother；
6. 核对所有 lifecycle 节点、最终速度发布拓扑，并确认未发送目标时
   `/cmd_vel` 静默。

任一步失败，脚本都会停止容器。`navigation-diagnostic` 模式把最终输出隔离到
`/cmd_vel_diagnostic`，并强制确认真实 `/cmd_vel` 为零发布者。启动入口本身不
发送导航目标，目标仍必须经带超时和取消逻辑的安全客户端单独下发。

控制器保持本轮真机验收后的参数：RPP 内部角加速度上限 `10.0 rad/s²`，用于在
20 Hz 控制周期内越过实测死区；最终 velocity smoother 仍以
`±2.0 rad/s²` 管理真实跟随和制动。二者职责不能互换。

## 3. Isaac 回归结果

主机 `isaac-sim` 容器内结果：

- Python/配置/ROS 契约测试：`43 passed, 8 skipped`；跳过项是容器内不具备的
  ROS/xacro 可选依赖，不是失败。
- Isaac Lab 无界面环境 smoke：成功退出。
- 1 m 直行：车体与轮速里程均为 `0.9935 m`，横向误差与航向误差为零，最终速度
  为零。
- 对称转向：正反向各 `138.69°`，回转误差 `0.00°`，位置漂移约 `0.0028 m`，
  最终速度为零。
- 看门狗：指令丢失后在 `0.510 s` 触发，最终速度为零。

回归后主机 Isaac 容器已停止。上述结果验证的是软件契约和理想运动层，不替代剩余
真机标定。

## 仍然明确保留的阻塞项

这些项目不阻塞当前软件提交，但仍阻塞无人值守自主运行和策略发布：

- 标准硬件急停尚未安装；手机红色按钮和临时断电开关不能等同于独立硬件急停。
- 质量、质心、惯量、履带摩擦，以及代表性地面/载荷尚未系统标定。
- MID-360 精确 XY/RPY 与内部 IMU 杠杆臂仍需外参标定。
- ESP32 时间同步仍需周期重同步与单调时间戳策略，接收抖动/重复样本仍需处理。
- 域随机化范围有物理证据，但仍不是统计置信区间；`policy_release_blocked` 保持
  `true`。

下一轮应从“充电并恢复安全条件后部署新启动脚本、做一次无目标静默启动验收”开始，
而不是重新做人工长距离测量。
