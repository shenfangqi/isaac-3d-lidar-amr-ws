# 2026-09-16 Carbot 落地标定

- 地面：木地板。载荷：空载（外加 payload `0 kg`）。
- 安全措施：外置 ESP32 人工断电开关可立即触及；标准硬件急停仍未安装。
- ESP32 boot ID：`2401686156`。
- 时间同步：`/carbot/status.time_synchronized=true`。

## 短点动

执行 `0.05 m/s`、`0.5 s` 前进点动：

- 现场确认顺利起步、基本直行，停止后无异常报告。
- 左/右编码器增量分别为 `379 / 385 ticks`，按
  `0.000087602 m/tick` 预测约 `3.32 / 3.37 cm`。
- 现场测得左/右侧位移约 `4.0 / 3.3 cm`。
- 最后一次 tick 变化发生在非零命令发布结束约 `571 ms` 后，最后 0.5 秒
  ticks 保持不变，程序随后补发 10 次零速度。

该试验用于确认落地起步和停车。由于基线只有约 3–4 cm，人工起止点误差占比过大，
左右测量也与编码器差分方向不一致，因此不将其拟合为有效侧滑/轮径修正参数；参数
估计改用至少 0.5 m 的直线试验。

## 前进 10 秒直线试验

执行 `0.05 m/s`、`10 s` 前进，原始数据为 `forward_0p05_10s_bag`：

- 左/右编码器增量：`4962 / 5045 ticks`。
- 编码器预测左/右距离：`0.434682 / 0.441953 m`，平均 `0.438317 m`。
- 现场测得左右位移均为 `0.441 m`；测量分辨率内未见横向偏移。
- 纵向滑移定义为 `1 - 实测距离 / 编码器预测距离`，本轮为 `-0.006121`
  （约 `-0.61%`，即编码器平均距离略低估实测距离）。
- 等效半径估计为 `0.021883 m`，相对 `0.02175 m` 基线约增加 `0.61%`。
- 左右编码器差分预测 yaw 为 `0.028626 rad`（约 `1.64°`），但现场左右位移
  相同。直线试验不据此拟合有效轮距，后续用独立角度真值完成转向标定。
- 最后一次 tick 变化发生在命令发布结束约 `615 ms` 后，最后 0.5 秒 ticks
  保持不变，并补发 10 次零速度。

单次 0.441 m 结果已经说明半径基线接近，但不足以替代协议要求的正/反向重复试验
和不同地面/载荷样本。

## 反向 10 秒直线试验

执行 `-0.05 m/s`、`10 s` 后退，原始数据为 `reverse_0p05_10s_bag`：

- 左/右编码器增量：`-4784 / -5003 ticks`。
- 编码器预测左/右距离绝对值：`0.419088 / 0.438273 m`，平均
  `0.428681 m`。
- 现场测得左/右后退距离：`0.430 / 0.445 m`，平均 `0.4375 m`，现场观察
  有轻微倾斜。
- 平均纵向滑移为 `-0.020573`（约 `-2.06%`），单次平均等效半径为
  `0.022197 m`。
- 左/右距离比例分别对应约 `0.022316 / 0.022084 m` 的单侧等效半径，说明
  反向存在明显左右不对称；这项差异应优先在电机控制/PID 层复查，不直接写成
  几何轮距修正。
- 最后一次 tick 变化发生在非零命令发布结束约 `648 ms` 后，最后 0.5 秒
  ticks 保持不变，并补发 10 次零速度。

木地板上当前两次直线试验的平均表观纵向滑移约为 `-1.33%`，对应两次等效半径
均值约 `0.022040 m`。由于每个方向只有一次试验，暂不修改运行参数。

## 第二次前进 10 秒直线试验

再次执行 `0.05 m/s`、`10 s` 前进，原始数据为
`forward_0p05_10s_repeat2_bag`：

- 左/右编码器增量：`4782 / 5022 ticks`。

- 现场测得左/右前进距离：`0.430 / 0.440 m`，平均 `0.435 m`，车头偏左；

目前三个木地板空载直线样本的表观纵向滑移均值约为 `-1.32%`，等效半径均值
约 `0.022038 m`。两个前进样本均值约为 `-0.96%`；参数仍保持不变，等待第二次

## 左转组合试验

先执行 `angular.z=+0.20 rad/s`、`8 s`，再追加同角速度 `4 s`。原始数据分别为
`turn_left_0p20_8s_bag` 与 `turn_left_supplement_0p20_4s_bag`：

- 第一段左/右 ticks 为 `-1093 / +1918`，现场估计约左转 `60°`。
- 第二段左/右 ticks 为 `-394 / +844`。
- 两段合计左/右 ticks 为 `-1487 / +2762`，编码器按 `0.254 m` 基线预测
  `83.963°`。
- 现场以初始标线测得最终比 90°少约 4°，即实测约 `86°`。
- yaw 增益（实测/编码器）为 `1.0243`，对应单次有效轮距 `0.247985 m`。
  与 `0.254 m` 基线相差约 `-2.37%`，说明 ticks→yaw 几何换算已经接近。
- 两段角速度指令积分合计 `137.51°`，实测仅约 `86°`，跟踪比例约 `62.5%`。
  主要偏差来自低速履带执行/死区/负载，而不是轮距参数。

左转仅有一个组合样本，暂不修改轮距。下一步需要对称的右转真值试验。

## 右转组合试验

先执行 `angular.z=-0.20 rad/s`、`12 s`，再追加同角速度 `2 s`。原始数据分别为
`turn_right_0p20_12s_bag` 与 `turn_right_supplement_0p20_2s_bag`：

- 第一段左/右 ticks 为 `+1487 / -2246`，编码器预测右转 `73.767°`；现场
  初估约 `75–80°`。
- 第二段左/右 ticks 为 `+430 / -477`，编码器预测右转 `17.923°`。
- 两段合计左/右 ticks 为 `+1917 / -2723`，编码器按 `0.254 m` 基线预测
  右转 `91.690°`。
- 现场以初始标线测得最终约右转 `92°`。
- yaw 增益为 `1.0034`，对应单次有效轮距 `0.253144 m`，与 `0.254 m`
  基线相差约 `-0.34%`。

左右组合转向的有效轮距分别为 `0.247985 / 0.253144 m`，均值为
`0.250564 m`。考虑左转角度为人工估计约 86°、右转约 92°，当前 `0.254 m`
基线已经处于测量不确定度附近，暂不修改；后续用更精确角度真值和 360° 重复试验
收敛。

## 动态 IMU 检查

对四个转向 bag 的三轴 `angular_velocity` 去除首尾静态中位数偏置并进行梯形积分：

- 左转 8 s：积分约 `[-0.01°, -0.01°, -1.03°]`。
- 左转追加 4 s：积分约 `[-0.00°, -0.01°, -0.42°]`。
- 右转 12 s：积分约 `[+0.03°, +0.02°, +1.23°]`。
- 右转追加 2 s：积分约 `[+0.01°, -0.00°, +0.30°]`。
- 各段 `gyro.z` 去偏置峰值仅约 `0.004 rad/s`。

车辆外部真值与编码器均显示约 86° 左转和约 92° 右转，因此 ROS IMU 的动态角速度
几乎没有响应。该现象不能用安装轴映射解释（三轴积分均接近 0），说明固件传感器读取、
量程换算或数据刷新路径还存在第二个问题。与已确认的加速度重复乘重力问题一起修复并
重刷前，`/imu/data_raw` 的线加速度和角速度都不得融合到定位。
